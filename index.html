Distribuidora Walter

                  
Ecosistema ERP & Microservicios Multiplataforma

                

              

              Full-Stack ERP
            


            

              Solución integral para gestión de bodegas, inventarios por lote con fechas de caducidad, compras, ventas POS, devoluciones, generación de facturas y órdenes en PDF, control de roles y permisos (Gerente, Vendedor, Administrador), y cuadros de mando ejecutivos con PowerBI embebido.
            


            

              

                
                Flutter Multiplataforma: Aplicación compilable a Android, iOS, Windows y Web con más de 20 vistas interactivas y arquitectura modular.
              

              

                
                ASP.NET Core Web API: Autenticación JWT, Identity, Claims personalizadas, Azure SQL, EF Core, trazabilidad con tabla Auditoría y Repositorios desacoplados.
              

              

                
                Microservicios (Stack 2026): Transición moderna con endpoints Swagger/OpenAPI, middleware de seguridad y servicios distribuidos.
              

              

                
                Web Admin & PowerBI: Tableros dinámicos en tiempo real con tokens de sesión y métricas clave de rotación comercial.

AgroVerde Analytics

                  
Minería de Datos, Machine Learning & Gobierno

                

              

              Data & AI Enterprise
            


            

              Plataforma analítica e industrial para la Cooperativa AgroVerde orientada a predecir caídas de rendimiento agrícola antes de cosecha. Integra un Data Warehouse SQL, pipeline en C# .NET para evaluación de calidad en 6 dimensiones y un motor ML en Python con blindaje anti-leakage.
            


            

              

                
                Modelos Predictivos Campeones: XGBoost y LightGBM con corrección de desbalance (`scale_pos_weight = 4.73`), alcanzando ROC-AUC de 0.9481 y Recall de 86.53%.
              

              

                
                Blindaje Anti-Leakage: Prohibición estricta y aislamiento de predictores directos del target (`rendimiento_ton_ha`) para garantizar validez en producción.
              

              

                
                Motor de Calidad C# .NET: Algoritmo de staging masivo con SqlBulkCopy, auditoría de 10,000 registros, 97.63% de registros conformes y cuarentena automática.
              

              

                
                Impacto Económico Demostrado: Alertas preventivas que proyectan salvar $164,050.00 USD anuales en cosechas vulnerables.
              

            

          


          

            

              Python
              XGBoost
              C# .NET
              SQL DataWarehouse

          EXPEDIENTE DE PROYECTO
          
Ecosistema Distribuidora Walter ERP

        

        
      


      

        
Descripción y Reto de Negocio

        

          Distribuidora Walter requería una plataforma integral de gestión comercial para unificar la operación de sus bodegas, el inventario clasificado por marcas, lotes y vencimientos, las compras a proveedores mayoristas y las ventas en tiempo real a clientes con emisión inmediata de comprobantes en PDF.
        


        
Componentes Técnicos Clave:

        
    
          
  • distribuidora-mobile-app (Flutter): Interfaz gráfica responsiva diseñada para móviles, escritorios y navegadores con sincronización HTTP contra la API central.
    • 
          
  • distribuidora-backend-api (ASP.NET Core 8): Capa de servicios RESTful asegurada con JWT Bearer y Entity Framework Core contra Microsoft Azure SQL.
    • 
          
  • distribuidora-microservices (Stack 2026): Arquitectura moderna desacoplada en microservicios, con Swagger interactivo para contratos de interfaz.
    • 
          
  • distribuidora-web-admin (Web & PowerBI): Panel con JavaScript ES6 y SDK de PowerBI Embedded para consulta de KPIs comerciales por la gerencia.
